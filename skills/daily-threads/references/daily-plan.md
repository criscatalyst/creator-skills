# Daily Plan — goal, structure, mix, CTA

How to turn mined material into a full day of posts that serves one goal.

## The three goals → what changes

| Goal | Optimize for | Templates that fit | CTA policy |
|---|---|---|---|
| **Grow on social** | Reach, follows, saves, replies | 0, 1, 4, 5, 7, 8, 9 (broad value + identity + reframes) | No selling. CTA = "follow for more" / "share this" only, and rarely |
| **Sell a product** | Demand for a specific offer | 0 (workflow → result), 4 (lessons → soft offer), 6 (transformation), 1 | Soft offer in 1-2 posts max, always after value. Show result, let demand build |
| **Create sales opportunities** | DMs, replies, "how do I…" Qs, warm leads | 6, 7, 8 (call-out + how-to), 0 (result that begs a question), 4 | End a post with a real question or an open loop. Invite replies/DMs, never pitch cold |

Confirm the goal with the user before writing. If they want a blend, pick ONE primary goal for the day and let one or two posts serve the secondary.

## Default day structure (5 posts)

| Slot | Time (local) | Role | Default format |
|---|---|---|---|
| 1 | 09:00 | Morning value or hot take | Thread (Template 0) if rich, single take if not |
| 2 | 11:00 | Remix / deep value | Thread or listicle (Template 1, 4) |
| 3 | 13:00 | Build-in-public / proof | Single ≤280 or short thread |
| 4 | 16:00 | Reframe / identity (US peak) | Mic-drop (2, 3, 7, 9) or rally (8) |
| 5 | 19:00 | Take / observation | Single ≤280 |

Offer a **lighter 3-post day** (09:00 value thread, 13:00 single, 19:00 reframe) when the user doesn't have much material or wants to start small. Quality over quantity always wins for a buyer audience.

Adjust times to the user's audience timezone. If they sell to the US, weight slots toward 16:00-22:00 their local US-evening.

## Mix rules (so the day isn't monotone)

- Don't stack two long threads back to back. Alternate long-form and one-liners.
- Vary the hook archetype across the day — don't open three posts the same way.
- At most one transformation post (Template 6) per day. It loses power if repeated.
- One post = one job. Don't merge a value thread and a pitch.
- Reuse one piece of mined material across at most 2 posts, each from a different angle (workflow vs result vs contrarian flip vs tool breakdown). This is the "remix" move: one idea → many posts.

## Remix angles (one idea → several posts)

From a single thing the user did, you can spin:
- **Workflow** → the step-by-step (Template 0)
- **Atomic tip** → one point expanded into a take or short thread
- **Before/after** → the result with real numbers
- **Contrarian flip** → the insight as a polarizing opinion (Template 7, 9)
- **Tool breakdown** → focus on the specific tool and how it works

## CTA rules

- Never hard sell. The sell is earned by value. Show the result; let people ask.
- Put a CTA only where it fits structurally (usually after a takeaway, or as the final part of a value thread). No fixed quota — forcing CTAs into posts that don't want them backfires.
- If selling: no price, no "X spots left" pressure unless the user explicitly wants urgency. Soft framing ("link in bio", "I show you how inside [thing]") converts better and reads less like a pitch.
- If generating leads: end with a genuine question or an open loop that makes replying/DMing natural.

## Delivery format (per post)

```
─────────────────────────────────────
SLOT n · HH:MM · [Format] · Goal: [grow/sell/leads]
─────────────────────────────────────

[finished post, copy-paste ready. Thread parts numbered 1/6, 2/6,
separated by a blank line]

WHY THIS WORKS:
• Hook archetype: [name] — [why it stops the scroll]
• Template: [name]
• [what it does for the goal]
```

Close the whole day with a one-line arc summary so the user sees the strategy at a glance.
