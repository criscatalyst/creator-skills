# Post Templates

11 proven structures. Pick by goal and by the kind of raw material you mined. Fill the skeleton with the user's real words, then run `writing-rules.md` over it.

**Universal rules for every template below:**
- No em dashes. Use a period.
- One idea per line. Aggressive line breaks.
- Each thread part ≤ 280 characters (works on Twitter and Threads).
- "I" or "you" inside the first 3 lines.
- ≤ 25 words per sentence. 5th-grade reading level.
- No all-caps phrases ("REAL TALK:", "SERIOUSLY!"). Lowercase + a line break does the same job.
- Max 3 emoji in a whole thread. Never 🚀 or 🔥.

---

## Template 0 — 6-Part Step-by-Step Thread  ⭐ default for "how I did X"

The single best-performing format for showing a workflow or a build. Use it when the user has a process, a build, or a "here's exactly how" story.

| Part | Role | Rule |
|---|---|---|
| **1/6 Hook** | Stop the scroll | Bold claim + contrast ("Not X. Not Y. Z.") + 🧵 |
| **2/6 Step 1** | First concrete step | One specific action, real detail |
| **3/6 Step 2** | Second step | Continues the workflow. Quotable standalone |
| **4/6 Step 3** | Third step | Continues the sequence |
| **5/6 Result** | The payoff | Concrete before/after. Real numbers if they exist |
| **6/6 Takeaway** | The wider lesson | Never a stub. No sales CTA unless the goal is sell/leads |

Hook patterns for part 1:
- `"I [did X]. Not with [common tool]. With [unexpected thing]. Here's how 🧵"`
- `"[Bold claim about the result]. Here's my entire workflow 🧵"`
- `"[Pain everyone has]. So I built [solution]. Here's how 🧵"`

Each part must survive being quoted alone. If part 3 quoted by a stranger makes no sense, rewrite it.

## Template 1 — Listicle Timeframe

**When:** the user has practical expertise built over time.

```
[Timeframe] doing [thing] taught me what actually works:

• [Action 1]   ← shortest
• [Action 2]
• [Action 3]
• [Action 4]
• [Action 5]   ← longest

Do those to [outcome] faster than everyone still [common excuse].
```

Rules: bullets cascade short→long (visual rhythm). 5-10 bullets, never more than 10. Each bullet 5-40 chars. Close with "Do those to X faster than everyone still Y."

## Template 2 — Stop / Start One-liner

**When:** a direct challenge, a scroll-stopper.

```
Real one.

Stop [common mistake]. Start [simple fix].

That is all.
```

Rules: one sentence per line, max 12 words each. Mic-drop close ("That is all.") optional. Lowercase opener ("Real one." / "Listen." / "Hot take.") — never caps.

---

## Template 3 — You Don't X, You Y

**When:** a mindset reframe in two lines.

```
You don't [undesired behavior].

You [desired behavior].
```

Rules: 2 lines total, each < 12 words. The contrast does all the work. Zero emoji. Example: `You don't grow by going viral. / You grow by going again.`

## Template 4 — Long-Form Viral Thread (lessons)

**When:** the user has 8-12 dense lessons from real experience and wants big reach. (If it's a linear workflow, use Template 0 instead.)

```
POST 1 — HOOK
I'm [age]. After [years] of [pain], here are [N] controversial [topic] lessons every [audience] should know.

POSTS 2..N+1 — LESSONS (most contrarian → most conventional)
1️⃣ [Title, 2-4 words, verb-led]
[WHAT, ≤25 words]
[WHY, ≤25 words]

POST N+2 — TL;DR
TL;DR — one ruthless list:
keyword — 5 words
keyword — 5 words

POST N+3 — QUESTION
Which lesson hits hardest for you? 👇

POST N+4 — CTA STACK (only if goal = grow/sell/leads)
➡ Follow for daily [topic].
↗️ Share post 1 so your people see it.
🗞 [Soft offer / link in bio].
```

Rules: 8-12 lessons, 60-100 words per post, lessons ordered contrarian→conventional. At least 1 stat + 1 metaphor across the thread. ≥1 power verb per post.

## Template 5 — Age + If-You-Feel Listicle

**When:** speaking to a specific segment with empathy.

```
I'm [age].

If you're [target group] and feel [emotion], do these [N] things:

• [Action 1: contrarian / attention-grabbing]
• [Action 2]
• [Action 3]
• [Action 4]
• [Action 5: most heartfelt]

Your [life phase] are for [unconventional focus], not [common path].
```

Rules: 5-13 bullets, odd numbers perform better. Each bullet ≤ 7 words. Open with a real age. Close with a reframe of the life stage.

## Template 6 — 1-3-1-3-1 Me-At-Age (transformation)

**When:** a credible before/after.

```
Me at [age then]:

• [Negative 1]
• [Negative 2]
• [Negative 3]

Me at [age now]:

• [Positive 1]
• [Positive 2]
• [Positive 3]

A lot can change in [X years]. [Punchline < 10 words].
```

Rules: exactly 3 + 3 bullets (perfect mirror). One line per bullet. **Only use if the before/after is verifiable** — never fabricate a transformation.

## Template 7 — Don't X, Verb Y (mic-drop)

**When:** reframe against a vanity metric in two lines.

```
Don't [conventional surface goal].

[Strong verb] [deeper alternative].
```

Rules: 2 lines, each < 12 words. Line 2 starts with a strong verb (Build / Craft / Forge / Shape / Design / Develop). Zero emoji. Simplicity is the punch.

---

## Template 8 — Raise Your Hand (identity rally)

**When:** filter the audience, build community, signal "you're my people."

Short:
```
Raise your hand if you don't care about [thing everyone obsesses over] 🙋
```

Extended:
```
Raise your hand if you:

• [Trait / milestone 1]
• [Trait / milestone 2]
• [Realization that connects]

[Closing line — "We're the same." / "This is our table."]
```

Rules: 1 emoji max, a real one (no 🚀/🔥). Make the closing line yours, not borrowed.

---

## Template 9 — Truth-Bomb Mic-Drop

**When:** a shareable truth in two lines.

```
Real one.

[Bold truth in one sentence, max 15 words].
```

Rules: 2 lines max, < 25 words total. The "X isn't Y, it's Z" structure works well. No emoji — the words carry the weight. Lowercase opener, never "REAL TALK:".

---

## Template 10 — I Don't Want To Be Rich For (mission)

**When:** tell the WHY, emotional + specific.

```
I don't want to be rich for the [plural status symbol].

I want to:
→ [Generous action for someone else]
→ [Action that removes a personal anxiety]
→ [Action that creates a priceless memory]

That's [the real concept — 2-3 words].
```

Rules: 5-6 lines. Verbs that evoke generosity, freedom, memory. Avoid vague ("help people", "travel"). Bullet 1 hits the heart, bullet 2 removes stress, bullet 3 is legacy/joy. Close in 2-3 words.

## Decision tree — which template

| Goal of the post | Use |
|---|---|
| Show a build / workflow | Template 0 (default), Template 1 |
| Big reach from many lessons | Template 4 |
| Fast mindset reframe | Template 2, 3, 7, 9 |
| Emotional pull / segment | Template 5, 8 |
| Transformation proof | Template 6 |
| Tell the why / mission | Template 10 |

**Combo for max reach:** Age hook + contrarian + list. e.g. "I'm 27. 6 years building X. 5 lessons every [audience] ignores:"
