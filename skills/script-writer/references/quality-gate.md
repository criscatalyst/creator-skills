# Quality gate

Run every check on the finished script. Any fail → rewrite that part, run the gate again.

## Attention
- [ ] **Second 1:** the first frame + on-screen text work with the sound off.
- [ ] **Second 3:** the loop is open. Can a viewer say what they're waiting for?
- [ ] **Every 6-8 seconds:** point at the line that re-hooks. A gap longer than 8s with nothing new → cut or add a beat.
- [ ] **Pattern interrupt:** at least one, and it's on the beat map.
- [ ] **Payoff position:** the loop closes in the last 20%, right before the CTA, not earlier.
- [ ] **Escalation:** each beat raises stakes or possibility. Name the flattest beat and fix it.

## Value
- [ ] **Visible proof:** every important claim has something on screen that proves it.
- [ ] **New information:** at least one thing the viewer didn't know (a mechanism, a number, a tool). If everything is common knowledge, the script isn't worth filming.
- [ ] **One real specific** the creator owns (their tool, number, result). No invented numbers, results or stories: if it isn't verifiable, cut it or ask for the real one.

## Voice
- [ ] Read it aloud at ~2.5 words per second: does it fit the target length? Count the words.
- [ ] Sounds like the creator's own lines (Step 0), not like a template. Contractions everywhere.
- [ ] No dead openers or stock phrases (list in `hook-engine.md`), no AI vocabulary ("delve", "unlock the power", "game-changer", "seamless", "in today's world").
- [ ] No em dashes. No rhythm tells: three parallel short sentences in a row, or "It's not X. It's Y." used more than once.
- [ ] The creator's own rules (from Step 0) are all satisfied. They win over this file.

## Ending
- [ ] The CTA promises the whole thing (the full setup, the full list), not a piece.
- [ ] Everything the CTA promises exists or is listed under TO PREPARE.

## The last question
Would the creator post this today, without edits, and expect it to beat their median? If the honest answer is no, name what's missing and fix it before delivering.
